# UI Brief（项目 v0.4 · 文档 v3.3）——内容中心 & 前台内容站改版

> 项目/里程碑版本：v0.4｜文档修订号：v3.3｜日期：2026-10-26。
> 配套文档：`docs/v0.4/v0.4_prd_20261026_v3.3.md`、`docs/v0.4/v0.4_technical_design_20261026_v3.3.md`。
> 本稿是视觉与交互实施依据；PRD 第一章为最高优先级。本稿不另行发明业务规则。

## 1. 设计语言与基础 token

- 风格：neo-lab；主色蓝 `#2563EB`，hover `#1D4ED8`；强调柠绿 `#CCFF00` 仅用于侧栏选中和精选徽章，徽章文字恒为 `#121316`。
- 浅色：页面/卡片 `#FFFFFF`，正文 `#121316`，次级 `#6B7280`，边框 `#E5E7EB`，hover `#F3F4F6`。
- 深色：页面 `#121316`，卡片 `#1F2937`，正文 `#F2F3F5`，次级 `#9CA3AF`，边框/hover `#374151`，链接/文字蓝 `#60A5FA`。
- 状态色：浅色成功 `#16A34A`、警告 `#D97706`、危险 `#DC2626`；深色成功 `#4ADE80`、警告 `#FBBF24`、危险 `#F87171`。
- 正文对比度 ≥4.5:1，大标题/图标 ≥3:1；禁用旧绿 `#10B981`、`emerald-*` 和绿色选中态。
- 字体沿用现有系统栈；正文 14px/1.6，说明 12–13px，区块标题 20px/600，KPI 数字 32px/600。
- 间距采用 4px 基线：字段间距 16px、卡片内边距 20px、卡片间距 16px、区块间距 24px；卡片圆角 12px、按钮/输入 8px、弹窗 12px。

## 2. 基础组件与状态规格

| 组件 | 默认/尺寸 | hover / focus | disabled / loading / error |
|---|---|---|---|
| 按钮 | 高 36px，水平 padding 16px；主蓝底白字、次按钮蓝边蓝字、危险红底白字 | hover 主色 `#1D4ED8`；2px 蓝色外焦点环，偏移 2px | disabled 不透明度 45%、禁点；loading 保留宽度并显示转圈；危险操作须确认 |
| 单行输入 | 高 36px，2px 边框，圆角 8px | hover 边框主色；focus 主色边框 + 焦点环 | disabled 灰底；error 红边 + 下方 12px 错误文案；失焦及提交校验 |
| 多行输入 | 最小 96px，自动增长至 400px | 同单行输入 | 超 400px 内部滚动；错误不撑破布局 |
| Select | 高 36px，统一箭头，无原生箭头；支持单/多选、搜索、清空 | 面板圆角 8px、阴影；选项 hover 使用主题 hover 色 | 加载显示骨架/转圈；空结果显示“暂无选项”；键盘上下键、Enter、Esc 可操作 |
| Toggle | 开蓝、关灰；带可读文本状态 | 可见焦点环 | 请求中禁用；失败恢复原值并 Toast |
| TagInput | chip 圆角 6px，右侧删除 ×；输入联想最多 8 条 | chip/删除按钮有 hover 和焦点 | 达 10 个或单条 20 字时输入区显示错误；组字中 Enter 不建标签 |
| BaseDialog | 小 400 / 中 640 / 大 880px；宽度不超过视口减 32px | 页头与底部固定，内容区滚动 | 大弹窗最大高 `min(90vh, 900px)`；中小弹窗最大高 85vh；表单脏数据关闭须确认 |
| Toast | 顶部统一反馈 | 成功/失败使用状态色及图标 | 不只靠颜色表达；错误可被屏幕阅读器读取 |
| 空态/骨架/失败 | EmptyState；加载用同布局骨架 | 不引发布局跳动 | 失败显示原因与“重试”；空态提供当前页可执行的主操作 |

所有交互组件支持 Tab 导航与可见焦点；弹窗打开后焦点进入首个字段、Tab 不离开弹窗，关闭后焦点返回触发按钮。

## 4. 前台页面布局

| 页面 | 桌面 ≥1280 | 平板 768–1279 | 移动 <768 |
|---|---|---|---|
| 文章/新闻列表 | 内容最大宽 1200px；每行一卡；左封面 240px、16:9，右标题/摘要/标签；20 条/页 | 封面 200px，其余不变 | 封面改顶部通栏 16:9；卡片内边距 16px；分页可折行 |
| 文章/新闻详情 | 正文最大宽 800px；封面通栏最高 400px；标题、meta、正文、上下篇、推荐依次排列 | 左右留白 32px | 左右留白 16px；长 URL/代码可换行或内部滚动；图片不溢出 |
| 推荐区 | 候选充足时固定 6 条，**3 列 × 2 行**；卡片含 16:9 封面、两行标题、标签 | 2 列 × 3 行 | 1 列 × 6 行；全站已发布候选不足 6 条时显示实际条数，不造空卡 |
| 精选区 | 1 大卡约 40% + 右侧小卡 **3 列 × 3 行**；不足 9 小卡保留网格空位 | 大卡满宽，小卡 2 列，按实际数量排 | 大卡满宽，小卡 1 列；不强制保留桌面空位 |
| 首页/语言切换 | 各语言前缀 URL；切换器与后台同顺序 | 同桌面 | 切换器不挤压标题，选项面板可滚动 |

## 5. 全站状态与内容溢出清单

- 每个列表/图表/详情都必须设计：初始加载、刷新加载、空数据、筛选无结果、请求失败、重试中、成功；无数据不能显示为 0 代替未知。
- 每个表单都必须有：必填、格式错误、服务端错误、提交中、提交成功、脏数据关闭确认；错误靠近字段且保留用户输入。
- 长标题最多两行并省略，完整值可查看；标签多时换行；无封面用浅色/深色对应占位图；图片加载失败同样回退占位。
- 正文加载期间编辑器禁用；上传图片时允许继续编辑但保存须等待上传完成；失败图片有重试/移除。
- 弹窗页头和页脚固定，只有内容区滚动；Esc/遮罩/×/取消行为一致；展示弹窗无脏数据确认。
- Toast 不能替代字段错误；危险操作不能只靠红色，必须有文字与确认。

## 6. R14/R15 逐页走查范围

- 后台：仪表盘、用量、财务、用户、渠道、设置、内容中心的文章列表/文章编辑/新闻管理/新闻编辑/新闻源/抓取规则/自动化/BI/AI 创作/模型配置。
- 前台：五语言首页、新闻列表、深度解析列表、文章详情、新闻详情；每类至少覆盖有/无译文和有/无封面。
- 每页在浅色/深色各取证；重点页补 1440×900、1024×768、390×844 三视口。检查统一组件、选中态、圆角、焦点、溢出、对比度，以及无原生下拉箭头和下划线输入框。

## 7. 多语言与可访问性

- 语言为 English / 中文 / Русский / Français / Deutsch，顺序与 `i18n/registry.ts` 一致。
- BI 的图例、坐标轴、tooltip、筛选和位置名均按界面语言翻译；不展示 `home_hero`、`duration_ms` 等代码。
- 正文无译文时仅正文回落中文，界面文案仍为 URL 指定语言；不跳转。
- 键盘可完成导航、弹窗、下拉、标签和分页；焦点顺序与视觉顺序一致；状态变化有文本，不仅依赖颜色。
