> 项目/里程碑版本：v0.4｜文档修订号：v3.3｜日期：2026-10-26。
> 需求基线：`docs/v0.4/v0.4_prd_20261026_v3.3.md`；技术基线：`docs/v0.4/v0.4_technical_design_20261026_v3.3.md`。
> 用例 ID 全文件唯一。表中“前置/操作”与“预期”即执行步骤和断言；UI 用例默认在浅色+深色执行，标有响应式的还需桌面/平板/移动。

## 0. 测试数据与通用环境

- 管理员与普通访客各一套；浏览器 Chrome/Edge/Safari 最新版；数据库含文章、新闻、分类、标签和五种 locale 的已发布/无译文/失败任务数据。
- 精选、SEO、BI 等使用可隔离测试数据；AI 使用受控 mock 与真实连通测试账号，不在报告记录 Key。
- 性能环境固定：生产构建、SSR 缓存分别冷/热、同区域客户端，记录 p50/p95/p99、样本数、并发、机器配置；功能验收门限采用 p95，连续 3 轮每轮 ≥100 请求。
