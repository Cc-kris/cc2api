## 二、关键端到端验收脚本

### A. 内容生产到公开阅读

1. 管理员新增新闻源并启用 en/ru/fr/de 自动翻译，触发一次抓取；记录新闻原文、封面和四语言任务状态。
2. 新增深度文章，上传封面、输入标签、生成 SEO，设置精选并发布；勾选译文。
3. 访客依次访问 `/zh/`、`/en/articles`、文章/新闻详情；检查封面、20 条分页、精选、推荐、译文和无译文回落。
4. 关闭 JavaScript 重取原始 HTML，确认正文、lang、canonical、robots、hreflang 为服务端输出。
5. 切换五语言与深浅主题，在 1440×900、1024×768、390×844 各留证据。

### B. AI 配置治理

1. 新建两个同厂商配置和另一个厂商配置，获取模型、测试连通、设置/切换默认；刷新确认仍保留全部配置。
2. 查看 Key 掩码，留空/掩码保存不覆盖；模拟加密缺失、并发 revision 冲突和默认删除，核对明确错误。
3. 分别执行文章生成、SEO、翻译；验证默认模型一致，未配置默认时三处均阻断并引导。

### C. 路由与 SEO 反例

- cookie=en 时 `/`、`/news`、`/articles` 必须分别 301 到 `/zh/`、`/zh/news`、`/zh/articles`，**不得以英文 200 通过**。
- `/articles/zh-CN/x`、`/news/en-US/x` 等长码必须 301 到短码；**同 URL 200 渲染不是通过**。
- 有效译文 self-canonical/index；无译文回落页 canonical 到中文版/noindex；sitemap 不列无译文版本。

### D. 数据与性能

- 精选迁移保留 ID 快照、顺序、来源并集和回滚证据；有差异禁止上线。
- BI 用固定样本手算访客/阅读/CTR/平均阅读时长，与页面及 API 对账；五语言截图齐全。
- SSR 和 BI 性能报告必须含环境、并发、样本数、p50/p95/p99 和三轮结果；单次数值或“感觉很快”不算证据。
