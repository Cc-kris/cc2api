# UI Brief v1.0 —— 内容中心 & 前台内容站改版

> 版本：v1.0 ｜ 日期：2026-10-24 ｜ 配套 PRD v3.1、技术方案 v1.0
> 本文描述视觉与交互设计，作为前端实现与 UI 验收的依据。所有改动遵守 PRD 第一章《全站统一规范》。

## 1. 设计语言（neo-lab 新风格）
- 主色蓝 `#2563EB`；强调柠绿 `#CCFF00`（仅侧栏选中、精选徽章）；文字墨黑 `#121316`；淘汰旧绿 `#10B981`。
- 双主题：浅色 / 深色（色值表见 PRD 1.1，此处不重复，以 PRD 为准）。
- 组件库：按钮/输入框/下拉/开关/弹窗/标签词条/徽章（规格见 PRD 1.3）。

## 2. 后台内容中心（ContentCenterView）
- **布局**：左侧栏导航 + 顶部 tab（新闻 / 文章 / AI 创作 / BI 分析）+ 内容区。
- **新闻管理**：列表 + 操作列。点「新增新闻源」弹独立弹窗；点「编辑」弹编辑弹窗；「抓取记录」弹查看弹窗（只读）。
- **文章管理**：列表含「精选」开关列（滑块，蓝/灰）。点「编辑」进编辑弹窗（左右结构）。
- **文章/新闻编辑弹窗**：左侧配置区（320px，标题/链接/分类/标签/时间/封面），右侧正文富文本编辑器占满剩余高度。标签为词条式 chip 输入，回车成词条。SEO 区含「SEO 自动化」按钮（生成描述+关键词）。
- **AI 创作**：顶部两个子 tab——文章生成 / 模型配置。模型配置为表单 + 已配置列表。
- **BI 分析**：顶部 4 个 KPI 卡（今日访客/浏览/阅读/平均点击率）+ 10 维度图表（2 列网格）。语言/位置筛选改下拉。图表中文标签、去旧绿。
- **定时任务区块**：开关滑块 + 统一输入框，对比度修正。

## 3. 前台公开站（PublicContentView）
- **首页 / 新闻 / 深度解析**三个板块，语言切换器与后台一致（5 种）。
- **深度解析精选区**：区块头（柠绿胶囊「精选深度解析」+ 副标题 + 「查看全部 →」）+ 1 大卡（最新精选：封面大图/标题/摘要/标签/阅读时间）+ 9 小卡（3×3 网格：封面缩略图/标题/标签）。卡片浅底深字、悬停上浮。
- **文章/新闻卡片**：16:9 封面缩略图（列表左侧 240px），无封面显示统一占位图。
- **详情页**：顶部通栏封面大图（≤400px），正文富文本样式渲染，底部「更多深度解析/更多新闻」推荐 6 条。
- **分页**：20 条/页，页码进 URL。

## 4. 交互规则（全站）
- 表单弹窗未保存时关闭弹确认；展示弹窗遮罩可关。
- 按钮顺序：取消（左）/保存（右）。
- 输入框内容多时自动伸缩（封顶 400px）内部滚动；正文编辑器占满剩余高度。
- 所有加载/失败/成功状态有明确反馈。

## 5. 多语言
- 5 种语言（en/zh/ru/fr/de），前后台同源；界面文案、图表标签、说明文字按界面语言切换；无译文内容回落中文。
