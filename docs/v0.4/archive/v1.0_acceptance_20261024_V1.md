# 验收标准 v1.0 —— 内容中心 & 前台内容站改版

> 版本：v1.0 ｜ 日期：2026-10-24 ｜ 配套 PRD v3.1、测试用例 v1.0
> 验收方式：**必须通过真实浏览器页面操作取证（截图/DOM 证据），不许只做接口验收**。每条给出：操作路径 → 预期 → 实际 → 结论（PASS/FAIL）。

## 验收维度（每条需求均需覆盖）
功能完整性 / 数据正确性 / 交互体验 / 异常处理 / 性能 / 兼容性（深浅主题 + 多语言）

## 各需求验收标准

### 第 0 步 统一基础组件
- [ ] 全站按钮/输入框/下拉/开关/弹窗/标签/徽章样式统一（双主题截图核对）
- [ ] 表单弹窗未保存关闭有确认；展示弹窗遮罩可关；按钮顺序左取消右保存

### R1 三个 bug
- [ ] S6：单源间隔保存后回显正确，实际抓取按该间隔（附证据）
- [ ] N5：长正文新闻编辑完整回显、保存后逐字一致
- [ ] P10：/en/news、/zh/articles 直接访问非 404
- [ ] 回归：内容中心所有现存按钮逐一点击无失效

### R2 新闻编辑弹窗
- [ ] 左右结构、右侧富文本占满剩余高度、内部滚动
- [ ] 粘贴清洗 script/大图转 URL；保存后内容逐字一致

### R3 二级功能弹窗化
- [ ] 新闻源新增/编辑、抓取记录、文章新增/编辑、标签分类管理、AI 生成均为独立弹窗/页面
- [ ] 弹窗交互符合统一规范

### R4 定时任务修样式
- [ ] 深/浅主题截图对比度达标；开关切换刷新状态保持；视觉统一

### R5 标签 + SEO
- [ ] 标签词条式唯一、中文输入法不误触发、联想去重
- [ ] SEO 按钮有真实结果：成功填入/覆盖确认/失败提示/未配置引导

### R6 精选
- [ ] 勾选/取消刷新保持；未发布不能精选；>10 篇精选区只显示前 10

### R7 封面
- [ ] 列表 16:9 缩略图、详情通栏大图、无封面占位图

### R8 分页
- [ ] 20 条/页、页码进 URL、精选不计入分页

### R9 多语言（重点）
- [ ] 勾选语言保存后自动生成译文存库
- [ ] /articles/<locale>/<slug> HTML 源码即译文（curl/查看源码验证）
- [ ] head 含 hreflang + canonical；sitemap 含所有语言版本
- [ ] 无译文语言显示中文原文不跳转；英文列表列全部
- [ ] 「更多深度解析」同标签/分类、固定 6 条、排除当前

### R10 AI 配置
- [ ] 模型配置全流程（新增/获取模型/设默认/测试连通）；Key 掩码；删除默认二次确认
- [ ] 文章生成/SEO/翻译均用默认模型，未配置时引导

### R11 BI
- [ ] 4 KPI 卡 + 10 维度图表逐项存在、中文标签、位置中文映射、去旧绿
- [ ] 埋点事件（referrer/时长/locale）入库可查

### R12 语言切换
- [ ] 前后台选项数量/顺序/名称一致；URL 语言优先；记忆 + 跨标签同步

### R13 精选区
- [ ] 1 大 + 9 小卡结构；深/浅主题标题对比度实测 ≥4.5:1；0 精选隐藏

### R14 风格收口
- [ ] 扫描 emerald-*/#10B981/border-bottom 残留为 0；4 类板块逐页走查

### R15 下拉/下划线
- [ ] 全站无原生默认下拉、无下划线输入框

## 验收流程
1. 按测试用例 v1.0 逐条执行并留证据。
2. 每条记录：操作路径 → 预期 → 实际 → PASS/FAIL。
3. 全部 PASS 且回归无失效 → 验收通过；有 FAIL → 记录根因并修复后复测。
