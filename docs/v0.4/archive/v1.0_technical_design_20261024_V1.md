## R6 精选勾选

- 改动：`ContentCenterView.vue`（精选开关）、`service/content_article_admin.go`、`handler/admin/content_article_handler.go`。

## R9 多语言自动翻译 + 相关推荐（最大改造，含 SSR）
- **SSR**：前台文章/新闻详情与列表页的服务端渲染需正确支持 locale 前缀（修 P10 的 404），URL 统一 `/articles/<locale>/<slug>`、`/news/<locale>/<slug>`，旧写法 301 重定向；页面 `<head>` 输出 hreflang 互标 + canonical；`sitemap.xml` 含所有语言版本；确保 HTML 源码即译文（Google 可爬）。
- **翻译**：文章编辑页加"同步语言"多选（en/ru/fr/de，主语言 zh）。保存/修改时，对勾选语言创建翻译任务（`POST .../translations/tasks`），后台用 AI 创作默认模型自动翻译成对应语言版本，存 `content_article_translations`。
- **缺失回落**：前端切到某语言，有译文显示译文，无译文显示中文原文（不跳转）。英文列表列全部文章（用户决策 B）。
- **相关推荐**：「更多深度解析」改为同标签→同分类→最新，固定 6 条，排除当前文章。
- 改动：`routes/public_content.go`、`service/public_content_service.go`（SSR+hreflang+sitemap）、`service/content_article_admin.go`（翻译任务编排）、`ContentCenterView.vue`（同步语言多选）、`PublicContentView.vue`（语言切换+回落+推荐）。

## 风险与回滚
- **SSR 性能**：详情/列表 SSR 需加缓存，避免每次渲染打 DB；回滚=回退到客户端渲染 + 修 locale 路由。
- **翻译质量**：自动翻译默认模型效果需抽验；回滚=翻译任务可取消、译文可下架（复用 unpublish）。
- **埋点数据量**：R11 埋点量增加，需确认 events 表索引与聚合性能。
- **整体回滚**：每需求独立改动、独立验收，可单点回滚；DB 变更前先备份。
