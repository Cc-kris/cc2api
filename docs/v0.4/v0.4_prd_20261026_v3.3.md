## 一、全站统一规范（所有需求共用，最高优先级）

> 本章是所有页面的"硬约束"，任何页面不得违反。**统一基础组件（1.3 节）是所有功能的前置，必须最先做（见实施顺序）。**

### 1.1 视觉规范（浅色 + 深色 双主题，色值定死）

**浅色主题**：
| 用途 | 色值 |
|---|---|
| 主色蓝（按钮底/链接/选中态/聚焦边框）| `#2563EB` |
| 主色蓝-hover | `#1D4ED8` |
| 强调柠绿（仅侧栏选中项背景、精选徽章）| `#CCFF00` |
| 正文主文字 | `#121316` |
| 次级/说明文字 | `#6B7280` |
| 页面底 | `#FFFFFF` |
| 卡片底 | `#FFFFFF` |
| 表头底/斑马纹 | `#F3F4F6` |
| 输入框底 | `#FFFFFF` |
| 边框 | `#E5E7EB` |
| hover 底 | `#F3F4F6` |
| 分隔线 | `#E5E7EB` |

**深色主题**：
| 用途 | 色值 |
|---|---|
| 主色蓝（按钮底/选中态）| `#2563EB` |
| **文字蓝/链接蓝**（深色底专用，区别于按钮底）| `#60A5FA`（实测在 `#121316` 上对比度 5.9:1，达标）|
| 强调柠绿（同浅色）| `#CCFF00` |

**状态色**（浅色 / 深色各一套，功能性状态不禁色）：
| 状态 | 浅色 | 深色 |
|---|---|---|
| 成功（已发布/启用/上升）| 绿 `#16A34A` | 绿 `#4ADE80` |
| 警告 | 橙 `#D97706` | 橙 `#FBBF24` |
| 危险（删除/失败/危险按钮）| 红 `#DC2626` | 红 `#F87171` |
| 信息 | 蓝 `#2563EB` | 蓝 `#60A5FA` |

**重要澄清**：1.1 说的"禁用绿色"**只针对选中态、主按钮、链接**这三类（避免旧的绿选中框残留）；**功能性的"成功/已发布/上升"状态仍用绿色**，用上面状态色表里的绿。两者不冲突。

**淘汰色**：旧绿 `#10B981`（emerald 系，含 `rgb(16,185,129)`、`emerald-*` 类名）全站清除。

### 1.2 可读性底线（验收硬性指标）
- 正文文字对比度 ≥ **4.5:1**，大号标题/图标 ≥ **3:1**。禁止浅色字压浅色底、深色字压深色底。
- 验收时用浏览器取色实测对比度（附计算过程），不许只凭肉眼说"看得清"。
- 强调柠绿 `#CCFF00` 上做文字时，**必须用深色字 `#121316`**（实测 15.81:1），禁止配白字（实测仅 1.18:1）。

### 1.3 统一基础组件（P0 第一步，所有功能复用）

先做这套组件，后续所有功能复用，不许各页面各写一套：

| 组件 | 规格 |
|---|---|
| 按钮 | 高 36px、圆角 8px、水平 padding 16px。主按钮=蓝底白字、次按钮=白底蓝边蓝字（深色主题=透明底蓝边浅蓝字 `#60A5FA`）、危险按钮=红底白字。 |
| 输入框（单行）| 高 36px、圆角 8px、2px 边框、聚焦时边框变蓝。**禁止下划线样式**。 |
| 输入框（多行）| 圆角 8px、2px 边框。**自动伸缩规则见 1.4**。 |
| 下拉框（单选/多选）| 全站**唯一组件**（复用项目现有 Select 组件，不引入新 UI 库）。高 36px、圆角 8px、2px 边框、右侧统一箭头图标（隐藏浏览器默认箭头）、下拉面板圆角 8px + 阴影。多选、可搜索、禁用、清空、加载中五种形态都要有。 |
| 开关 | 滑块式，开=主色蓝、关=灰。 |
| 弹窗 | 居中、圆角 12px、遮罩半透明黑。三档宽度：小 400px（确认类）/ 中 640px（表单类）/ 大 880px（编辑类，如文章/新闻编辑）。**底部按钮顺序：左取消、右保存**。保存成功后：关闭弹窗 + 顶部提示"已保存" + 刷新列表。必填项标红星 `*`，失焦即校验、提交前整体校验。 |
| 标签词条（chip）| 圆角 6px、浅色底（深色主题深底）、文字 + 右侧 × 删除。 |
| 徽章（分类/状态标签）| 圆角胶囊。精选徽章=柠绿底深字，分类徽章=浅灰底深字。 |

### 1.4 输入框高度规则（统一，消除 v3 的矛盾说法）

- **普通多行输入框**（描述、摘要、SEO 描述、新闻源描述等）：自动随内容增高，**初始最小 3 行（96px），最高 400px，超出后输入框内部滚动**。
- **编辑器**（文章/新闻正文）：**高度 = 弹窗内容区剩余高度，内容超出后在编辑器内部滚动**（编辑器本身不无限增高）。
- 一句话区分：**表单里的多行文本框自动伸缩（封顶 400px）；正文编辑器占满剩余高度、内部滚动**。
- 适用字段穷举：新闻源描述、文章摘要、SEO 描述、SEO 关键词说明、新闻/文章正文。

### 1.5 弹窗交互（统一）
- 四种关闭方式全开：右上角 ×、底部取消、点遮罩、Esc。
- **所有表单类弹窗**：有未保存修改时点任一关闭方式，弹「有未保存修改，确认离开？」（确认/继续编辑）。展示类弹窗（纯查看）不需要。
- 新增成功 = 关弹窗 + 提示 + 刷新列表。

### 1.6 文字与多语言（i18n 化）
- 后台界面可切 5 种语言，所有图表标签、说明文字、提示语按当前界面语言显示，**禁止出现字段名/代码值**。
- 业界缩写（UV/PV/CTR）保留，首次出现时旁边附中文说明（如「访客数(UV)」）。"首次"按**每个卡片**算，英文界面下显示对应英文全称。
- 前台各语言区块内不留半截中文半截外文（例外见 R9：正文无译文时回落中文，这是允许的）。

### 1.7 验收方式（强制）
- 每条需求验收必须通过真实浏览器页面操作取证（截图/DOM 证据），不许只做接口验收。
- 每条给出：操作路径 → 预期 → 实际 → 结论。

### R5｜新增文章：标签去重 + SEO 按钮修复

**位置**：内容中心 → 文章编辑（大弹窗）。

**标签**（词条式 chip，与 R2 共用同一组件）：
1. 输入框输入、**回车即生成一个标签词条**，每个词条右侧 × 可删除。
2. **中文输入法兼容**：组字过程中按回车（确认候选）不生成标签，只有组字完成后按回车才生成（用 `compositionstart/end` 处理）。
3. 输入时联想已有标签下拉供选择（输入第 1 个字开始联想，最多显示 8 条）。
4. 去重规则：不区分大小写、忽略首尾空格；逗号/顿号也可作为分隔符触发成词条。
5. 单篇最多 10 个标签，单个标签最长 20 字，超出时提示。
6. 新输入的标签保存时自动写入标签库。
7. 删掉独立的「新增标签」按钮。

**SEO 自动化按钮**：
1. 点击后自动生成「SEO 描述」和「SEO 关键词」填入对应框（**不生成 SEO 标题、不改 slug**，这两个保持手动）。
2. SEO 描述控制在 120-160 字符，SEO 关键词 5-8 个；结果越界时不得直接采用，自动重试一次，仍越界则提示生成失败并保留原字段。
3. 用的模型 = AI 创作配置的**默认模型**（见 R10）；没配模型时点击提示"请先在 AI 创作 → 模型配置里配置默认模型"。
4. 字段已有内容时先弹"已有内容，是否覆盖？"确认。
5. 生成中按钮变加载态（转圈+禁用）；失败弹提示；生成结果可手动再改。
6. 正文为空时按钮禁用。

**根因**："SEO 自动化按钮点击无效"是因为之前没有接真实后端接口（只有空壳），本次补真实接口。

**验收**：标签只剩词条式一种添加方式，中文输入法回车不误触发、联想正常、去重生效；SEO 按钮每次点击都有明确结果，字数符合要求，没配模型时有引导提示。

### R6｜文章列表「精选」勾选修复

**位置**：内容中心 → 文章列表的「精选」开关列。

**改法**：

### R9｜多语言自动翻译 + 相关文章推荐（重点需求）

**整体目标**：全站支持多语言，主语言中文。文章/新闻以中文为主，选定语言由系统自动翻译存库，前台按语言网址直接访问对应版本（服务端渲染 SSR，让 Google 能搜到译文），「更多深度解析」按同标签/同分类推荐。

#### 9.0 前台渲染方案（用户已确认 A 方案：上 SSR）
- 前台内容页（文章/新闻详情、列表）改为**服务端渲染**：直接访问各语言网址时，返回的 HTML 源码里就包含对应语言的完整正文（不依赖浏览器脚本加载）。
- 这是本次最大的技术改造，需先做前台 SSR 化（或预渲染直出），再做下面的翻译流程。
- **语言记忆用 cookie 存**（服务端渲染时服务端只能读 cookie，不能用 localStorage）。

#### 9.1 支持语言与同步多选
1. 支持语言 = 全站语言切换下拉的另外 4 种（**英语、俄语、法语、德语**），与界面语言同源，以后增减语言自动同步。
2. 文章/新闻编辑弹窗加「同步语言」多选框（checkbox 列表：英/俄/法/德，默认全不勾）。
3. 勾选后，**新建/修改保存时**，后台自动调用 AI 把标题、摘要、正文、SEO 字段翻译成勾选语言，各自存成一条独立的语言版本记录。
4. 新闻抓取入库后也按**全局语言设置**自动翻译（全局语言设置 = 一个开关列表，在「自动化设置」里配置默认要翻哪几种）。

#### 9.2 翻译执行
- **翻译用的模型 = AI 创作里配置的默认模型**（见 R10）。
- 翻译是**异步队列**：保存后主文章立即返回，译文在后台逐个生成；列表页加一列「翻译状态」（待翻译/翻译中/已完成/失败），失败的可点「重试」。
- 取消勾选某语言 = 前台该语言版本下架（标记下架，不删数据）；重新勾选 = 直接恢复（不重新翻译，除非主文又改过）。
- 主文章修改后，已勾选语言的译文**自动重新翻译覆盖**（保留最新的自动译文）。
- **不提供"查看/编辑译文"的界面**（用户明确说后面有另外的功能迭代，本期不做）。
- 若主内容本身是英文（如抓来的英文新闻），中文为主语言的规则不变，仍按勾选语言翻译。

#### 9.3 前台多语言访问与缺失回落
- 每种语言一个独立网址，**格式统一为 `/articles/<语言>/<slug>`、`/news/<语言>/<slug>`**（语言码 en/zh/ru/fr/de；**中文也带 `/zh` 前缀**，即 `/articles/zh/xxx`，与现有路由和 `(locale, slug)` 唯一索引一致，改动最小——v3.2 产品决策①）。
- slug 用中文原文的 slug（不翻译 slug，避免同一文章多个 slug 分散收录）。
- 旧的**详情页**写法 `/articles/<slug>`（不带语言码）一律 **301 跳转**到 `/articles/zh/<slug>`。
- 列表页与首页多语言 URL 采用**前缀式**（v3.2 产品决策②）：`/{lang}/news`、`/{lang}/articles`、`/{lang}/`（lang 为 en/zh/ru/fr/de）；不带前缀的 `/news`、`/articles`、`/` 一律 301 到 `/zh/...` 前缀版。旧写法 301 映射表见技术方案 §3 URL 矩阵。
- 本期翻译范围：文章**和新闻**（v3.2 产品决策③）——新闻详情页同样按上述规则出译文版网址。
- **前台切到某语言时**：有该语言译文 → 显示该语言版本；**没有该语言译文 → 显示中文原文，不跳转**（用户确认 B 方案）。界面文案保持所选语言，只正文回落中文，这是允许的例外（不视为"半截中外文"）。
- **缺失译文的 SEO 处理**：在 `/articles/de/xxx` 下显示中文原文时，该网址标 `noindex`，canonical 指向中文版，hreflang 和站点地图里**不列**该语言版本（避免被判重复内容）。
- **canonical/hreflang 按是否有已发布译文分别处理**：
  - 有已发布译文：该语言页 `canonical` 指向自身绝对 URL，`robots=index,follow`；hreflang 只列中文及已有已发布译文的语言，并含 `x-default` 指向中文版。
  - 无已发布译文、回落中文：该语言页 `noindex,follow`，`canonical` 指向中文版绝对 URL；hreflang 与站点地图均不列该语言。
  - 中文版始终 self-canonical；站点地图只列中文版和已有已发布译文的版本。
- HTML 示例：有效英文页为 `<link rel="canonical" href="https://<host>/articles/en/x">`；无德文译文的 `/articles/de/x` 为 `<link rel="canonical" href="https://<host>/articles/zh/x">` + `<meta name="robots" content="noindex,follow">`。
- 服务端渲染确保源码即译文；上述 SEO 标签必须出现在原始 HTML，不由客户端脚本补写。

#### 9.4 「更多深度解析」推荐
- 文章详情页底部的「更多深度解析」改为：**与当前文章同标签或同分类的其他文章，固定 6 条**，排除当前文章本身。
- 多标签文章：命中任意一个共同标签即算同标签；候选按"共同标签数多的优先，其次按发布时间新的优先"排序。
- 同标签不足 6 条时，先用同分类补、再用最新文章补齐。
- 只推荐已发布的文章；当前语言下优先推荐有该语言译文的。
- 新闻详情的「更多新闻」同样规则（新闻无标签时按同分类 → 最新补）。
- **保留**详情页原有的「上一篇/下一篇」导航（10-18 需求），不要删。

**验收**：①SSR 生效——直接访问 `/articles/en/xxx`，HTML 源码里就有英文正文；②勾选英语+法语保存后两种译文异步生成、列表显示翻译状态、失败可重试；③站点地图只列有译文的版本，缺失语言版标 noindex；④前端切英文显示英文版、切到没译文的语言显示中文原文不跳转；⑤「更多深度解析」固定 6 条、确为同标签/同分类、排除当前文章；⑥「上一篇/下一篇」保留。
