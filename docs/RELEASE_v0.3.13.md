# v0.3.13 — V03 计费与资金准确性

本版以 v0.3.12 发布提交 `cc91ab3b9` 为基线，选择性移植 V03；不包含 v0.4 内容中心，不从内容中心开发分支整体合并。

## 更新内容

### 计费与资金

- 统一余额扣减、Key 配额和用量记录的八位小数量化，保留去重指纹兼容性及促销余额财务口径。
- 修复同账号重试被误按强制缓存计费的问题；实际换号仍保留原有策略。
- 补齐流中断已产生用量、兼容接口客户端断开、换号续写和任务池关停窗口的计费路径，防止漏记或重复扣费。
- 管理员余额不足退款要求显式强制确认；强制退款只扣现有可用余额。完善退款 pending 查询、成功终结、失败恢复余额、并发与幂等处理。
- 订阅续期和邀请码领取增加事务/并发保护。

### 定价与审计

- 完善服务档位计费及只降不升规则，支持渠道独立 1h 缓存写入价与图片输入 token 价。
- 增加分组按张计费开关，补齐 Gemini 多图片输出计数。
- 长上下文按目录阶梯对整次请求计价，保留分组开关；目录缺失时保留 GPT-5.4/5.5 的基线 272K 阶梯，显式目录/override 优先。
- 支持价格 override 热重载，并在非法配置时保留上次有效价格。
- 增加显式会话 ID、上游响应模型、模型不一致、上游请求 ID、请求推理强度审计字段，以及管理员查询、筛选、列设置和导出。
- 增加余额模式 Redis 在途预占，减少并发请求共同透支余额的情况。

### 界面与稳定性

- 同步管理员退款、渠道、分组、账号、用量界面及多语言文本。
- 修复嵌入页面条件缓存与 CSP nonce 不一致造成的公共配置脚本被阻止问题。
- 手机端费用统计保留完整八位小数，避免金额溢出。
- 增加隔离的桌面/手机真实 UI 验收入口；本地支付测试传输仅在专用 E2E 构建标签下启用，正式发布不启用。
- 构建工具链升级到 Go 1.27.4，并更新 Brotli、Zstandard 压缩依赖，修复安全扫描发现的可达漏洞。
- 更新 Vue I18n 与 SheetJS，移除不再需要的过期安全例外；前端 CI 使用 Node.js 24，与 Docker 构建保持一致。SheetJS 固定为官方 CDN 的 0.20.3 包并校验完整性。

## 升级注意

- 新增迁移 **225–228、230–232**。请先备份数据库；231、232 使用非事务并发索引。若 `usage_logs` 是分区表，应先验证并调整索引执行方案，不能把本地非分区测试当作生产验证。
- 长上下文费用可能与旧版边际分段算法不同，尤其 Gemini 和历史 Claude 长上下文模型。请核对目录、override 和分组 `long_context_pricing_enabled`。
- **在途预占默认开启**：`billing.inflight_reservation.enabled=true`。需要渐进启用时，可先显式设为 `false`。订阅分组不预占；Redis 故障时按 fail-open 策略放行。
- 分组 `image_count_billing` 默认关闭；新增图片输入价和 1h 缓存写入价留空时保持对应旧价回退。
- 调用管理员退款 API 的集成方需处理 `require_force` 确认契约及 `REFUND_PENDING` 状态。
- 从 v0.3.12 升级不需要引入内容中心迁移。曾运行 v0.3.11 遗留的内容表不会被本版使用或删除。
- 此次发布不执行生产部署；生产分区表检查、生产迁移结果、预发 24 小时对账和上线后观察不包含在本地验收结论中。
